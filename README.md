Nombre Proyecto "Automatización de solicitudes académicas con Blue Prism"

Descripción: "La directora de la escuela de informática de Duoc UC, sede San Bernardo, gestiona de forma manual un alto volumen de solicitudes académicas. Entre estas, los tickets por renuncia destacan por ser procesos rutinarios que generan una alta carga administrativa, restando tiempo a la toma de decisiones estratégica de la dirección.
Para optimizar esta gestión, se propone un proyecto de automatización mediante Blue Prism. El cual iniciará como un prototipo para validar la eficiencia del robot en el ingreso al CRM y la gestión de datos. Tras el éxito de esta fase, se proyecta escalar la solución a las demás escuelas de la sede y, posteriormente, a nivel institucional.
"

Tecnología: 
1.-BluePrism Enterprise 7.5
2.-SQL SERVER  
3.- .NET Framework 4.8 o superior
4.-Extensión de Automatización del complemento de Blue Prism para Google Chrome (v7.4).

Instrucciones para ejecutar el proyecto localmente : no aplica ya que depende de credenciales y autorización por parte de cliente
